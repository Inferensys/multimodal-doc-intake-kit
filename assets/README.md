# Demo Assets

This directory stores screenshots and short recordings used in the README.

## Suggested Captures

- `intake-job-timeline.png`
  - stage transitions for one `document_id`
- `field-review-console.png`
  - low-confidence field queue and correction panel
- `chunk-provenance-view.png`
  - chunk text with page/bbox provenance markers

## Capture Guidelines

- Use 1440px wide viewport.
- Mask tenant identifiers and storage URIs.
- Keep a stable seed document so screenshots remain reproducible.
- Prefer PNG for static UI and GIF/WebM for process walkthroughs.
